# jFreeze — единый интерфейс (UI)

Стек UI: бесплатные библиотеки (React, Tailwind). См. [FREE_STACK.md](./FREE_STACK.md).

## Цель

Один визуальный язык для всех экранов: холодильная тема, предсказуемая навигация, повторяемые блоки. Пользователь всегда понимает, где он и что делать дальше.

## Принципы

1. **Мобильный first** — узкая колонка (max 32rem), нижняя навигация, крупные зоны нажатия.
2. **Три слоя экрана** — верхняя панель (хром) → заголовок страницы → секции с контентом.
3. **Семантика цвета** — не декор: sky = действие, emerald = хранение/холод, violet = AI, amber = сроки/внимание.
4. **Минимум кастома на странице** — страницы собираются из `Screen`, `Section`, `Panel`, `StatCard`, `NavCard`.

## Токены (`globals.css`)

| Токен | Назначение |
|-------|------------|
| `--brand` | Основной акцент (кнопки, активная навигация) |
| `--brand-muted` | Фон градиента шапки приложения |
| `--surface` | Карточки и панели |
| `--border` | Рамки карточек |
| `--radius` | Скругление (12px) |

## Компоненты (`src/components/ui/`)

| Компонент | Роль |
|-----------|------|
| `Screen` | Вертикальный ритм страницы (`space-y-4`) |
| `PageHeader` | Заголовок + описание + action |
| `Section` | Подзаголовок раздела + контент |
| `Panel` | Карточка с вариантом: default, accent, ai, storage, warning |
| `StatCard` | Метрика на главной |
| `NavCard` | Строка меню «Ещё» |
| `SegmentedControl` | Переключатель зон (холодильник / морозилка) |
| `ActionBar` | Ряд кнопок с единым gap |
| `LoadingBlock` | Состояние загрузки |
| `icons` | SVG-иконки навигации (без emoji) |

## Оболочка

- `AppTopBar` — логотип, «назад» на вторичных маршрутах, быстрый вход в настройки.
- `BottomNav` — 5 вкладок, активная с подложкой.
- `AppShell` — градиентный фон + отступ под safe-area.

## Маршруты

**Основные** (нижняя навигация): `/`, `/orders`, `/fridge`, `/cart`, `/more`

**Вторичные** (кнопка «назад» → `/more`): `/settings`, `/storage`, `/family`, `/pro`

## Паттерн страницы

```tsx
<Screen>
  <PageHeader title="…" description="…" />
  {error && <StatusBanner … />}
  <Section title="…">
    <Panel variant="accent">…</Panel>
  </Section>
</Screen>
```
