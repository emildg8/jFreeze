# IMAP — автоматический импорт заказов из почты

Бесплатно, без облачных сервисов jFreeze: подключение идёт **напрямую** с вашего сервера/ПК к почтовому ящику.

## Где настроить

**Ещё → Источники заказов → вкладка IMAP**

1. Нажмите пресет **Gmail**, **Яндекс** или **Mail.ru** (подставится хост и порт).
2. Укажите email и **пароль приложения** (не основной пароль).
3. Включите «Авто-проверку почты» и **Сохранить**.
4. **Синхронизировать почту** — загрузка до 50 писем за выбранный период.

## Пароли приложений

| Провайдер | Где создать |
|-----------|-------------|
| Gmail | [Google Account](https://myaccount.google.com/) → Безопасность → Пароли приложений |
| Яндекс | [id.yandex.ru](https://id.yandex.ru/) → Пароли приложений |
| Mail.ru | Настройки почты → Пароль для внешнего приложения |

## Как работает импорт

- Письма за последние N дней (по умолчанию 30) из папки INBOX (или другой `mailbox`).
- Автоопределение магазина по отправителю и теме (`store-sources.ru.json`).
- Импортируются только **включённые** магазины на вкладке «Магазины».
- Дубликаты отсекаются по хешу текста письма.

## Безопасность

Пароль хранится в локальной SQLite (`apps/web/data/jfreeze.db`). Не коммитьте базу в git.

## API

`POST /api/sources/sync` — ответ: `{ imported, scanned, skipped, message }`.

## Ограничения

- До **50** писем за один запуск (защита от таймаута).
- Только IMAP (POP3 — вручную через `.eml`).
- На Vercel/serverless длинная синхронизация может оборваться — лучше свой VPS или `npm run dev` локально.
