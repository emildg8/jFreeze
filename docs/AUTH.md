# Авторизация и личный кабинет

Вход: **телефон (OTP)**, **почта (magic link)**, **Google**, **Apple**.  
Без входа приложение работает в **гостевом режиме** (данные на этом устройстве).

## Быстрый старт (локально)

```bash
cp apps/web/.env.example apps/web/.env.local
# Задайте AUTH_SECRET (openssl rand -base64 32)
npm run dev
```

Откройте `/login` или **Ещё → Аккаунт**. С `AUTH_DEV_OTP=1` код OTP виден на экране.

## Страницы

| URL | Описание |
|-----|----------|
| `/login` | Вход |
| `/account` | Личный кабинет (только после входа) |

## Безопасность

- OTP действует **10 минут**, повторная отправка — не чаще **1 раза в минуту**
- После **5 неверных попыток** код сбрасывается — запросите новый
- `callbackUrl` после входа ограничен путями приложения (защита от open redirect)
- В production код SMS **не показывается** в UI (только через `SMS_WEBHOOK_URL` или dev-режим)

## Настройка (.env)

Обязательно:

```env
AUTH_SECRET=...   # случайная строка, openssl rand -base64 32
```

Опционально (включайте нужные способы):

| Переменные | Способ |
|------------|--------|
| `AUTH_URL` | Базовый URL приложения (prod / e2e) |
| `AUTH_GOOGLE_ID`, `AUTH_GOOGLE_SECRET` | Google |
| `AUTH_APPLE_ID`, `AUTH_APPLE_SECRET` | Apple |
| `SMTP_HOST`, `SMTP_PORT`, `SMTP_FROM`, `SMTP_USER`, `SMTP_PASSWORD` | Почта |
| `SMS_WEBHOOK_URL` | Телефон (ваш шлюз SMS, BYOK) |
| `AUTH_DEV_OTP=1` | Показывать OTP в UI (разработка) |

## Телефон без платного SMS

1. `AUTH_DEV_OTP=1` — код виден на экране входа после «Получить код».
2. Или `SMS_WEBHOOK_URL` — POST `{ "phone": "+79...", "code": "123456" }` на ваш бесплатный/свой шлюз.

## Данные пользователя

После первого входа гостевые заказы/холодильник (профиль `default` на этом сервере) **переносятся** в аккаунт.

Таблицы: `auth_user`, `auth_account`, `auth_session`, `phone_otps`.

## API (для UI)

| Метод | Путь | Назначение |
|-------|------|------------|
| GET | `/api/auth/providers` | Какие способы входа настроены |
| POST | `/api/auth/phone/send` | Отправить OTP |
| GET | `/api/auth/linked` | Привязанные способы (нужна сессия) |
