# Интеграции с магазинами

Подключения — **без платных API** на старте: демо, CSV, ручной ввод. См. [FREE_STACK.md](./FREE_STACK.md).

## Статус

| Магазин | MVP | Комментарий |
|---------|-----|-------------|
| Демо | ✅ | Тестовые заказы для онбординга |
| Ручной ввод | ✅ | Форма / API |
| CSV / JSON | ✅ | `name,qty,unit,date` |
| Озон | 🔜 | Нет consumer API; Seller API только для продавцов |
| Самокат | 🔜 | Нужно партнёрство |
| Пятёрочка | 🔜 | Программа лояльности, нет публичного API |
| Перекрёсток | 🔜 | Аналогично |

## План подключения

1. **Экспорт / CSV** — пользователь выгружает историю (если магазин даёт)
2. **Email-чеки** — парсинг писем (этап 2)
3. **Browser extension** — импорт с веб-кабинета (этап 3)
4. **Официальный API** — при соглашении с ритейлером

## Умный холодильник

Интерфейс `FridgeVisionProvider` позволит подключить MQTT/Home Assistant вместо фотографирования.
