# Интеграции с магазинами

Подключения — **без платных API** на старте: демо, CSV, ручной ввод. См. [FREE_STACK.md](./FREE_STACK.md).

## Чеки (реализовано)

На странице **Заказы** → блок «Загрузить чек»:

| Способ | Формат | Стоимость |
|--------|--------|-----------|
| Файл | CSV, TXT, PDF, EML | $0 |
| Фото | JPEG, PNG, WebP | $0 без AI; с ключом OpenAI — распознавание |
| Почта | Вставка текста письма или `.eml` | $0 |

API: `POST /api/receipts/import` (multipart или JSON подтверждение).

**Почта без IMAP:** сохраните письмо как `.eml` (Gmail «Показать оригинал» → скачать, Outlook «Сохранить как») или скопируйте текст чека из письма OFD/Ozon/банка.

## План подключения магазинов

1. **Экспорт / CSV** — пользователь выгружает историю (если магазин даёт)
2. **Чеки** — фото / PDF / почта (см. выше)
3. **Browser extension** — импорт с веб-кабинета (этап 3)
4. **Официальный API** — при соглашении с ритейлером
