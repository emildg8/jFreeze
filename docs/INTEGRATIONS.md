# Интеграции с магазинами

Подключения — **без платных API** на старте: демо, CSV, ручной ввод, **почта и SMS**. См. [FREE_STACK.md](./FREE_STACK.md).

## Источники заказов (реализовано)

Страница **`/sources`** (меню «Ещё» → «Источники заказов»):

| Канал | Как использовать | Стоимость |
|--------|------------------|-----------|
| **Почта** | Вставка текста письма или файл `.eml` | $0 |
| **SMS** | Вставка одного или нескольких SMS (через пустую строку) | $0 |
| **Магазины** | Включить Озон, WB, банки и т.д. — для подсказок при разборе | $0 |
| **IMAP** | Gmail / Яндекс / Mail.ru — пароль приложения только в локальной SQLite | $0 |

API:

- `GET /api/sources` — каталог магазинов РФ и настройки каналов
- `PATCH /api/sources` — включение магазинов, IMAP
- `POST /api/sources/import` — импорт из почты/SMS (multipart)
- `POST /api/sources/sync` — синхронизация IMAP (последние N дней, до 50 писем)

Детектор отправителя и ключевых слов: `src/data/store-sources.ru.json`.

Дубликаты отсекаются по хешу текста (`source_imports` в SQLite).

## Чеки (реализовано)

На странице **Заказы** → блок «Загрузить чек»:

| Способ | Формат | Стоимость |
|--------|--------|-----------|
| **QR ОФД** | Строка QR, ссылка 1-ОФД, фото QR | $0 |
| Файл | CSV, TXT, PDF, EML | $0 |
| Фото | JPEG, PNG, WebP | $0 без AI; с ключом OpenAI — распознавание |
| Почта | Вставка текста письма или `.eml` | $0 |

Подробно: [OFD.md](./OFD.md)

API: `POST /api/receipts/import` (multipart или JSON подтверждение).

**Почта без IMAP:** сохраните письмо как `.eml` (Gmail «Показать оригинал» → скачать) или используйте раздел **Источники**.

## План подключения магазинов

1. **Источники** — почта и SMS (автоопределение магазина)
2. **Экспорт / CSV** — пользователь выгружает историю (если магазин даёт)
3. **Чеки** — фото / PDF / OFD
4. **IMAP** — автоматическая выборка писем (реализовано)
5. **Browser extension** — импорт с веб-кабинета (этап 3)
6. **Официальный API** — при соглашении с ритейлером
