# Расширение для браузера (Chrome / Edge)

Бесплатное MV3-расширение в `extensions/browser/` — отправка текста чека или письма в jFreeze без копирования вручную.

## Установка (режим разработчика)

1. Запустите jFreeze: `npm run dev` (или укажите URL продакшена в popup).
2. Chrome → `chrome://extensions` → **Режим разработчика** → **Загрузить распакованное**.
3. Папка: `extensions/browser`.

## Настройка

Откройте иконку расширения → укажите **Адрес jFreeze** (по умолчанию `http://localhost:3000`) → **Сохранить**.

## Использование

| Способ | Действие |
|--------|----------|
| **Выделение** | Выделите текст чека → ПКМ → «Отправить в jFreeze» |
| **Почта / маркетплейс** | На Gmail, Ozon и др. — кнопка **→ jFreeze** (отправляет текст страницы) |
| **Подтверждение** | Если API вернул превью — откройте **Заказы** в приложении и подтвердите импорт |

API: `POST /api/receipts/import` (тот же разбор, что вкладка «Почта» в приложении).

## Ограничения

- Нужен доступный сервер jFreeze (локально или по HTTPS).
- CORS не мешает: расширение запрашивает URL из `host_permissions`.
- Импорт идёт в **сессию браузера** (`credentials: include`): войдите в jFreeze в той же вкладке/домене, что указан в popup.
- Автологин магазинов не поддерживается — только текст/чек, как в MVP.
