# Экспорт и интеграции (история заказов)

Бесплатная выгрузка без сторонних SDK. См. [FREE_STACK.md](./FREE_STACK.md).

## Выгрузка из приложения

**Экран:** `/export` (Ещё → «Экспорт и интеграции») или блок на странице **Заказы**.

| Формат | Расширение | Назначение |
|--------|------------|------------|
| Excel | `.xls` | SpreadsheetML — открывается в Microsoft Excel |
| CSV | `.csv` | UTF-8 с BOM, разделитель `;` — Google Таблицы, 1С |
| JSON | `.json` | Скрипты, n8n, Make, свои приложения |

**Структура:** каждая строка = одна позиция в заказе (удобно для сводных таблиц и фильтров).

Колонки: ID заказа, дата, магазин, сумма заказа, товар, количество, единица, категория.

## API

```
GET /api/orders/export?format=xls|csv|json
GET /api/orders/export?format=csv&sinceDays=90
```

Ответ — файл с заголовком `Content-Disposition: attachment`.

> Pre-alpha: API без токена, только на вашем локальном/PWA-сервере. Не публикуйте инстанс в интернет без авторизации.

## Куда импортировать

| Приложение | Как |
|------------|-----|
| **Microsoft Excel** | Скачать «Excel (.xls)» |
| **Google Таблицы** | Файл → Импорт → CSV или Excel |
| **Notion** | Import → CSV → сопоставить колонки |
| **Airtable** | Import data → CSV |
| **1С / учёт** | Загрузка CSV (`;`, UTF-8) по правилам вашей конфигурации |
| **Home Assistant** | REST sensor на `.../api/orders/export?format=json` (локальная сеть) |
| **Telegram / WhatsApp** | Кнопка «Поделиться» — текст + ссылка на экспорт |

## Обратный импорт в jFreeze

| Направление | Способ |
|-------------|--------|
| В jFreeze | CSV в **Настройки**, почта/SMS в **Источники**, чеки на **Заказы** |
| Из Excel | Сохранить лист как CSV (разделитель `;`) и импортировать |
