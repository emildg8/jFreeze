# QR чеков ОФД

Импорт кассовых чеков по QR без платных API (базовый режим — бесплатно).

## Где

**Заказы → Загрузить чек → вкладка «QR ОФД»**

- Вставьте строку QR (`t=…&s=…&fn=…&i=…&fp=…`)
- Или ссылку с чека (`https://consumer.1-ofd.ru/v1?...`)
- Или **QR с фото** (распознавание в браузере)
- Или **Сканировать QR камерой** (на странице «Заказы» вкладка ОФД открыта по умолчанию)

## Как получаем позиции

1. **Токен Proverka Cheka** — **Настройки → ОФД / Proverka Cheka** или env `PROVERKA_CHEKA_TOKEN` (BYOK) — полный список товаров через API
2. **HTML с сайта ОФД** — парсинг текста чека (1-ОФД и др.)
3. **Только сумма из QR** — одна строка «Покупка по чеку ОФД»; позиции можно отредактировать перед сохранением

## API

`POST /api/receipts/ofd` — тело `{ "qr": "..." }`, ответ как у импорта чеков.

## Переменные окружения

| Переменная | Назначение |
|------------|------------|
| `PROVERKA_CHEKA_TOKEN` | Опционально: токен proverkacheka.com для детального чека |
