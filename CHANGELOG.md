# Changelog

## [Unreleased]

_Планируется в следующих pre-alpha._

## [0.2.6-pre-alpha] — 2026-06-01

### Добавлено

- **Telegram → холодильник / заказы:** импорт фото из семейной ленты (`POST /api/telegram/inbox/:id/import`)
- Чек ОФД из подписи к фото в Telegram (QR в caption)
- Токен **proverkacheka.com** в настройках (BYOK), приоритет над env
- Панель «Из Telegram» на странице холодильника
- Загрузка **нескольких фото** из галереи (объединение списка)
- Типы холодильника: компактный, встраиваемый

### Улучшено (включено 0.2.5)

- Фото без OpenAI: пустой список + «вручную» / «пример»; превью; лимит 8 МБ
- Сроки годности при сохранении с фото (`defaultExpiryDate`)
- Панель модели: свёрнутая после сохранения, статус AI
- OpenAI Vision: устойчивый JSON, уточнённый промпт

## [0.2.4-pre-alpha] — 2026-06-02

### Добавлено

- **Модель холодильника:** тип из каталога или своя марка (`/fridge`, настройки)
- **Распознавание по фото:** OpenAI Vision с учётом модели; демо-список без ключа
- Кнопки «Сфотографировать» / «Из галереи», уверенность AI, правка списка перед сохранением
- Расстановка продуктов с подсказками под выбранный тип холодильника

## [0.2.3-pre-alpha] — 2026-06-02

### Добавлено

- **Заказы → холодильник:** кнопка «В холодильник из заказа», API `POST /api/orders/:id/to-inventory`
- **Корзина → холодильник:** «Купил — в холодильник» (принять все позиции, обновить запасы)
- Сроки годности по категории при переносе из заказа (`defaultExpiryDate`)

### Исправлено

- IMAP, источники заказов и семейные профили привязаны к `userId` сессии (не только гость `default`)
- GET `/api/cart` возвращает корзину текущего пользователя; купленные позиции скрываются (`accepted`)

### Улучшено

- Семья (Pro): удаление дополнительных профилей

## [0.2.2-pre-alpha.2] — 2026-06-02

### Исправлено

- Расходы за 7 дней и сроки годности считаются по `userId` сессии (не смешиваются с гостем)
- API `/api/expiry` учитывает владельца данных

### Улучшено

- Главная: баннер гостю «Сохраните прогресс в аккаунте», подсказка в HomeGuide
- Личный кабинет: статистика расходов и сроков для вошедшего пользователя

## [0.2.2-pre-alpha] — 2026-06-01

### Добавлено

- **Личный кабинет** (`/account`): вход, профиль, привязки OAuth
- Auth: телефон (OTP), email, Google, Apple — см. `docs/AUTH.md`
- Middleware: защита `/account`, редирект гостей

### Улучшено (UX)

- Плавающая кнопка «Чек», кликабельная статистика, обновление ↻ на главной и заказах
- Холодильник: ввод закреплён снизу, Enter для добавления
- Заказы: `?scan=1` открывает камеру; подтверждение чека закреплено над меню
- Корзина: кнопка «Собрать» всегда под рукой
- Главная: подсказки «что делать дальше», первичная кнопка «Сканировать чек»
- Онбординг: путь «у меня есть чек», ссылки на холодильник и корзину
- Понятные сообщения об ошибках API и обрыве сети (мобильный сервер)
- Корзина и заказы: пустые состояния с действиями; совет по QR только для новичков
- Расходы по категориям: инсайт «больше всего на …»
- **Ещё → Аккаунт**: карточка входа / «Вы вошли как …»; аватар в шапке

### Безопасность (auth)

- OTP: TTL 10 мин, cooldown 60 сек, сброс после 5 неверных попыток
- `callbackUrl` ограничен путями приложения (open redirect)
